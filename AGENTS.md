# Agent Instructions

Before making frontend or UX changes in this repository, read `design-system/MASTER.md`.

Design work must follow the Leadium CRM design stance:
- Keep the app operational, dense, and calm.
- Prefer clear workflow improvements over decorative UI.
- Do not add duplicate panels or cards when an existing view already owns the job.
- Use existing visual tokens and page patterns unless a broader refactor is explicitly requested.
- For complex user decisions, prefer guided steps over a single overloaded control.
- Verify frontend build after user-facing UI changes.

When a request mentions visual polish, UI quality, or design direction, treat `design-system/MASTER.md` as the source of truth and adapt external design ideas to this CRM instead of copying them directly.
